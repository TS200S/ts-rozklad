# TS Розклад — Security Test Suite

## Локальний запуск

Потрібен Node.js 18+.

```bash
npm run security:test
```

Або:

```bash
node security-test.js
```

Скрипт перевіряє:

- генерацію та перевірку 6-значних кодів;
- відхилення неправильних/пошкоджених кодів;
- rate limit;
- ліміти перебору кодів за акаунтом та IP;
- атрибути `HttpOnly`, `Secure`, `SameSite`, `__Host-` cookie;
- відсутність Bearer Authorization як механізму сесії;
- отримання сесії тільки з cookie;
- прив'язку сесії до device ID + User-Agent;
- автоматичне відкликання сесії при невідповідності пристрою;
- відсутність видачі сирого session token як public session ID;
- очищення секретів з журналу активності;
- ліміт журналу активності у 1000 записів;
- синтаксис усіх Netlify Functions;
- актуальну версію пакета.

## Результат

Команда завершується кодом `0` тільки якщо всі перевірки пройдені. При будь-яком FAIL процес завершується кодом `1`.

## Важливо

Це автоматичний локальний тест логіки. Він не заменяет интеграционный тест на реальном Netlify с подключенными Netlify Blobs и SMTP/email credentials.

После деплоя отдельно вручную проверить:

1. обычный вход;
2. неверный пароль и блокировку после лимита;
3. новый device + email-код;
4. неверные 2FA-коды и блокировку challenge;
5. смену пароля;
6. восстановление пароля;
7. создание/смену пароля админки;
8. критическое действие с admin password + email 2FA;
9. аварийное восстановление админского пароля;
10. завершение отдельной и всех других сессий;
11. вход с другого устройства с тем же session cookie — должен быть отклонён;
12. журналы пользователя и администратора;
13. смену email и письмо пользователю;
14. бан/разбан и IP-блокировку.
