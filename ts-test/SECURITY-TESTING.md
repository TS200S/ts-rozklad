# TS Розклад — Security Test

## Автоматична перевірка

У корені проєкту:

```bash
npm install
npm run security:test
```

Тест перевіряє security primitives, cookies, device binding, rate limits, журнал, синтаксис Functions, CSP та Service Worker.

## Онлайн-перевірка після Netlify deploy

Окремо вручну перевір:
- вхід / вихід;
- новий пристрій і email-підтвердження;
- критичну дію адміна → пароль адмінки → email 2FA;
- неправильні 2FA-коди та ліміти;
- завершення окремої сесії / усіх інших;
- зміну та аварійне відновлення пароля адмінки;
- актуальність розкладу після изменения в іншому браузері;
- відсутність помилок Service Worker / CSP у DevTools Console.

Не запускай навмисний масовий перебір на бойовому сайті.
